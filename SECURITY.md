# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private security
advisory form:

<https://github.com/hoangnguyen2003/edgar-moe/security/advisories/new>

Do not include API keys, database URLs, personal data, or other secrets in a
public issue. If private reporting is unavailable, open a minimal issue asking
for a private contact channel without disclosing the vulnerability details.

## Scope

Reports about the public research terminal, API boundary, CI workflows, and
deployment configuration are in scope. The project is a personal research
platform, so availability issues caused by ordinary free-tier limits are not a
security vulnerability unless they expose data or credentials.

Please include reproducible steps, the affected commit or deployment URL, and
the smallest evidence needed to confirm the issue. We will acknowledge reports
when practical and avoid publishing details until a fix or mitigation is
available.
